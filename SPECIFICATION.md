# Спецификация приложения для кампиметрии

## Обзор

Веб-приложение для проведения кампиметрического исследования — диагностики центрального поля зрения с целью выявления скотом (слепых пятен) и других нарушений.

## Цели

- Самостоятельное тестирование поля зрения в домашних условиях
- Скрининг для раннего выявления глаукомы, макулодистрофии, неврологических нарушений
- Мониторинг динамики заболеваний
- Генерация отчётов для врача-офтальмолога

## Технологический стек

- **Frontend:** React 19 + Vite
- **Сборка:** Single-file bundle (vite-plugin-singlefile)
- **Платформа:** Веб-браузер (Chrome, Firefox, Safari)

## Функциональные требования

### 1. Калибровка экрана

**Цель:** Определить реальный размер пикселя на экране пользователя.

- Отображение эталонного объекта (кредитная карта, монета, линейка)
- Пользователь вводит размер объекта или перетаскивает границы
- Вычисление DPI/PPI экрана
- Сохранение калибровки в localStorage

### 2. Настройка теста

| Параметр | Значения | По умолчанию |
|----------|----------|--------------|
| Тестируемый глаз | Левый / Правый / Оба поочерёдно | Правый |
| Расстояние до экрана | 30-50 см | 40 см |
| Размер стимула | I-V по Goldmann | III |
| Яркость стимула | 0-315 ASB (децибелы) | Адаптивно |
| Длительность стимула | 100-500 мс | 200 мс |
| Область тестирования | 10°, 20°, 30° от центра | 20° |
| Стратегия | Пороговая / Надпороговая / SITA-подобная | Надпороговая |

### 3. Процедура тестирования

#### 3.1 Подготовка
- Инструкция для пациента с анимацией
- Проверка освещения (через камеру, опционально)
- Напоминание закрыть/прикрыть нетестируемый глаз
- Точка фиксации в центре экрана

#### 3.2 Ход теста
- Случайное предъявление стимулов в заданной области
- Пациент нажимает клавишу/касается экрана при обнаружении стимула
- Фиксация времени реакции
- Контроль фиксации взгляда:
  - Периодические catch trials (ложные стимулы в слепом пятне)
  - Опционально: отслеживание взгляда через веб-камеру

#### 3.3 Адаптивный алгоритм (пороговая стратегия)
```
1. Начать с надпорогового стимула (например, 24 dB)
2. Если виден → уменьшить яркость на 4 dB
3. Если не виден → увеличить яркость на 2 dB
4. Повторять до схождения (2 реверса)
5. Записать пороговое значение для точки
```

### 4. Сетка тестовых точек

Поддерживаемые паттерны:
- **24-2:** 54 точки, 6° интервал, центральные 24°
- **10-2:** 68 точек, 2° интервал, центральные 10° (макула)
- **30-2:** 76 точек, 6° интервал, центральные 30°
- **Пользовательский:** Задание координат вручную

### 5. Визуализация результатов

#### 5.1 Карта чувствительности
- Числовая карта (dB в каждой точке)
- Градиентная карта (grayscale)
- Цветовая карта (от зелёного к красному)
- Паттерн-девиация (сравнение с нормой)

#### 5.2 Индексы
- **MD (Mean Deviation):** Среднее отклонение от нормы
- **PSD (Pattern Standard Deviation):** Локальные дефекты
- **VFI (Visual Field Index):** Процент сохранного поля зрения
- **GHT (Glaucoma Hemifield Test):** Сравнение верхней и нижней полусфер

#### 5.3 Показатели надёжности
- Ложноположительные ответы (%)
- Ложноотрицательные ответы (%)
- Потери фиксации (%)

### 6. История и отчёты

- Сохранение результатов в localStorage / IndexedDB
- Экспорт в PDF
- Экспорт данных в JSON/CSV
- Графики прогрессии MD по времени
- Сравнение нескольких тестов

## Нефункциональные требования

### Производительность
- Точность таймингов стимула ±10 мс
- Использование `requestAnimationFrame` для синхронизации
- Минимальные задержки отклика на ввод

### Доступность
- Поддержка клавиатуры (пробел для ответа)
- Крупные элементы UI для людей с плохим зрением
- Высокий контраст интерфейса
- Голосовые инструкции (опционально)

### Приватность
- Все данные хранятся локально
- Нет отправки на сервер без явного согласия
- Возможность очистки всех данных

### Совместимость
- Адаптивный дизайн (desktop, tablet)
- Fullscreen API для минимизации отвлечений
- Работа в автономном режиме (PWA-ready)

## Экраны приложения

1. **Главная** — выбор действия (новый тест / история / настройки)
2. **Калибровка** — настройка размера экрана
3. **Настройка теста** — параметры исследования
4. **Инструкция** — обучение перед тестом
5. **Тест** — основной экран исследования

7. **История** — список предыдущих тестов
8. **Настройки** — общие параметры приложения

## Ограничения и disclaimer

> **Внимание:** Данное приложение предназначено только для скрининга и самоконтроля. Оно НЕ заменяет профессиональное офтальмологическое обследование. При обнаружении отклонений обязательно обратитесь к врачу.

### Известные ограничения:
- Точность зависит от калибровки экрана
- Домашние условия не эквивалентны клиническим
- Нет стандартизированного контроля освещения
- Самоконтроль фиксации менее надёжен
