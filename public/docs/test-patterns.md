# Паттерны тестовых точек

## Обзор

Приложение поддерживает три стандартных паттерна Humphrey Field Analyzer, которые различаются плотностью и областью покрытия поля зрения.

## 24-2: Стандарт для глаукомы

### Спецификация

- **Количество точек:** 54 + слепое пятно
- **Сетка:** 6° × 6° интервал
- **Покрытие:** ±24° от центра фиксации
- **Центральные точки:** Смещены на ±3° (избегание фиксации)
- **Длительность теста:** ~6 минут (пороговая стратегия)

### Расположение точек

```
Координаты: от -24° до +24° по X и Y
Эксцентриситет: до 27°
Исключения:
  - Центральная точка (0, 0)
  - Точки > 27° эксцентриситета
  - Диагональные углы (±24°, ±24°)
```

### Почему 24-2, а не 30-2?

Исследования показали, что 90% глаукоматозных дефектов на ранних стадиях локализуются в центральных 24° [1]. Паттерн 24-2:

✅ **Оптимальная чувствительность** к ранним дефектам
✅ **Меньше времени** тестирования (~6 минут vs ~8 минут для 30-2)
✅ **Выше воспроизводимость** (меньше утомления)
✅ **Стандартизация** для клинических исследований

**Источники:**
- [1] Heijl A, et al. "Reduction of intraocular pressure and glaucoma progression: results from the Early Manifest Glaucoma Trial." Arch Ophthalmol. 2002;120(10):1268-79.

### Клиническое применение

- **Первичная диагностика глаукомы**
- **Мониторинг прогрессирования**
- **Скрининг населения**
- **Стандарт для клинических исследований**

**Файл реализации:** `src/utils/gridPatterns.ts:42-100`

## 10-2: Макулярное тестирование

### Спецификация

- **Количество точек:** 68
- **Сетка:** 2° × 2° интервал (плотная)
- **Покрытие:** ±10° от центра
- **Центральные точки:** Смещены на ±1°
- **Длительность теста:** ~8 минут (больше точек)

### Расположение точек

```
Координаты: от -10° до +10° по X и Y
Эксцентриситет: до 11°
Исключения:
  - Центральная точка (0, 0)
  - Точки > 11° эксцентриситета
```

### Почему плотная сетка 2°?

Макула требует **высокой пространственной точности:**
- Фовеа: диаметр ~1.5° (острота зрения)
- Парафовеа: 1.5-2.5° (критична для чтения)
- Макула: до 10° (центральное зрение)

Сетка 6° пропустила бы мелкие центральные скотомы!

### Клиническое применение

**Показания:**
1. **Глаукома с центральной фиксацией** — до 80% пациентов имеют дефекты в центральных 10° [2]
2. **Макулярная дегенерация** — мониторинг географической атрофии
3. **Макулярные отеки** — диабетическая ретинопатия, венозные окклюзии
4. **Макулярные дыры** — пред- и постоперационная оценка

**Источники:**
- [2] Hood DC, et al. "Glaucomatous damage of the macula." Prog Retin Eye Res. 2013;32:1-21.

**Файл реализации:** `src/utils/gridPatterns.ts:106-162`

## Слепое пятно

### Анатомия

**Слепое пятно (papilla)** — область на сетчатке, где зрительный нерв выходит из глаза. Здесь нет фоторецепторов, поэтому эта зона физиологически слепа.

### Расположение

| Глаз | Координаты | Радиус проверки |
|------|-----------|-----------------|
| Правый (OD) | 15° назально (вправо), -1.5° вниз | 5° |
| Левый (OS) | -15° назально (влево), -1.5° вниз | 5° |

**Формула определения:**
```typescript
const blindSpotX = isRightEye ? 15 : -15;
const blindSpotY = -1.5;
const distance = √((x - blindSpotX)² + (y - blindSpotY)²);
return distance < 5;
```

### Клиническое значение

1. **Контроль фиксации** — периодические стимулы в слепом пятне (не должны быть видны)
2. **Расширение слепого пятна** — признак отёка диска зрительного нерва
3. **Исключение из тестирования** — точки помечаются как `isBlindSpot: true`

**Файл реализации:** `src/utils/gridPatterns.ts:29-36`

## Генерация и обработка точек

### Алгоритм генерации

```typescript
// 1. Генерация сетки
for (let y = -range; y <= range; y += step) {
  for (let x = -range; x <= range; x += step) {
    // Избегаем центра (фиксация)
    if (x === 0) x = onAxisOffset;
    if (y === 0) y = onAxisOffset;

    const eccentricity = Math.sqrt(x**2 + y**2);

    // Фильтрация по эксцентриситету
    if (eccentricity > maxEccentricity) continue;

    points.push({ id: `${x}:${y}`, x, y, eccentricity });
  }
}

// 2. Маркировка слепого пятна
points = markBlindSpotPoints(points, isRightEye);

// 3. Случайная перестановка (Fisher-Yates)
points = shufflePoints(points);
```

### Фильтрация UI-зон

Перед началом теста точки фильтруются, чтобы не накладываться на элементы интерфейса:
- Кнопка ESC (левый верхний угол)
- Индикатор глаза (правый верхний угол)
- Прогресс-бар (верх)
- Инструкции (низ)

**Файл реализации:** `src/utils/uiZoneDetection.ts`
