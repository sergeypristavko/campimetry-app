# Система калибровки

## Зачем нужна калибровка?

Периметрия требует точного преобразования **угловых координат** (градусы поля зрения) в **пиксели экрана**.

**Проблема:** Разные мониторы имеют разный DPI (dots per inch):
- Ноутбук: ~96-110 DPI
- Внешний монитор: ~90-120 DPI
- Retina/HiDPI: ~200-300 DPI
- 4K монитор: ~140-180 DPI

**Последствия ошибки:**
- Ошибка ±10% → смещение стимула на 2-3°
- Критично для интерпретации результатов
- Может привести к ложным дефектам

## Метод калибровки: Кредитная карта

### Почему кредитная карта?

**ISO/IEC 7810 ID-1** — международный стандарт [1]:
- **Ширина:** 85.60 мм (±0.1 мм точность)
- **Высота:** 53.98 мм
- **Толщина:** 0.76 мм

**Преимущества:**
- ✅ Универсальная доступность (~3.6 млрд карт в мире)
- ✅ Жёсткая структура (не деформируется)
- ✅ Высокая точность производства
- ✅ Не требует дополнительных инструментов

**Альтернативы:**
- Монеты (меньше точность, диаметр варьируется)
- Линейка (менее доступна)
- A4 лист (деформируется, низкая точность)

**Источник:**
- [1] ISO/IEC 7810:2019 "Identification cards — Physical characteristics"

## Расчёт DPI (Dots Per Inch)

### Формула

```typescript
DPI = (ширина_карты_в_пикселях / 85.6 мм) × 25.4 мм/дюйм
```

### Пример расчёта

**Шаг 1:** Пользователь измеряет карту на экране
```
Измерено: 323 пикселя
```

**Шаг 2:** Расчёт DPI
```typescript
DPI = (323 / 85.6) × 25.4
    = 3.773 × 25.4
    ≈ 95.8 DPI
```

**Файл реализации:** `src/utils/calibration.ts:23-25`

## Расчёт Pixels Per Degree (PPD)

### Формула

**Pixels Per Degree** — количество пикселей, соответствующих 1° поля зрения.

```typescript
// Шаг 1: Расстояние в пикселях
расстояние_px = расстояние_см × (DPI / 2.54)

// Шаг 2: PPD через тангенс
PPD = расстояние_px × tan(1°)
    = расстояние_px × 0.017455
```

### Пример расчёта

**Дано:**
- Расстояние до экрана: 40 см
- DPI: 96

**Расчёт:**
```typescript
// Шаг 1
расстояние_px = 40 × (96 / 2.54)
              = 40 × 37.8
              ≈ 1512 пикселей

// Шаг 2
PPD = 1512 × 0.017455
    ≈ 26.4 пикселя/градус
```

**Проверка:**
```
1° на расстоянии 40 см = 2 × 40 × tan(0.5°) ≈ 0.698 см
0.698 см × (96 / 2.54) ≈ 26.4 пикселя ✓
```

**Файл реализации:** `src/utils/calibration.ts:36-43`

## Преобразование координат

### Градусы → Пиксели

```typescript
function degreesToPixels(degrees: number, ppd: number): number {
  return degrees × ppd;
}
```

**Примеры:**
```
6° × 26.4 PPD = 158.4 пикселя
15° × 26.4 PPD = 396 пикселя (слепое пятно)
24° × 26.4 PPD = 633.6 пикселя (край 24-2)
```

### Пиксели → Градусы

```typescript
function pixelsToDegrees(pixels: number, ppd: number): number {
  return pixels / ppd;
}
```

### Экранные координаты стимула

```typescript
// Центр экрана
const centerX = screenWidth / 2;
const centerY = screenHeight / 2;

// Преобразование координат точки (градусы)
const xPixels = point.x × pixelsPerDegree;
const yPixels = -point.y × pixelsPerDegree; // Инвертируем Y

// Абсолютные координаты
const screenX = centerX + xPixels;
const screenY = centerY + yPixels;
```

**Примечание:** Y инвертируется, т.к. экранные координаты растут вниз, а поле зрения — вверх.

**Файл реализации:** `src/utils/stimulusCalculations.ts:29-38`

## Точность калибровки

### Источники ошибок

| Источник | Величина | Процент |
|----------|----------|---------|
| Измерение карты | ±2-3 пикселя | ±1-2% |
| Расстояние до экрана | ±2 см (при 40 см) | ±5% |
| Позиционирование головы | ±1-2 см | ±2-3% |
| Неидеальная фиксация | ±1-2° | ±2% |
| **Общая ошибка** | | **~5-7%** |

### Клиническое влияние

**Сценарий:** 7% ошибка калибровки

```
Истинная точка: 10°
Отображается как: 10.7° (смещение 0.7°)

Для паттерна 24-2 (шаг 6°):
  Влияние: 0.7° / 6° = 11.7% смещения
  Приемлемо для скрининга ✓
```

**Сравнение с клиникой:**

| Параметр | Приложение | Humphrey Field Analyzer |
|----------|------------|-------------------------|
| Калибровка | Кредитная карта (~5-7%) | Лазерная (~0.1%) |
| Расстояние | Измерение (~±5%) | Подбородник (±0%) |
| Фиксация | Визуальная точка | ИК-трекинг |

**Вывод:** Приемлемо для домашнего скрининга, но не для точной диагностики.

## Процесс калибровки

### Шаг 1: Подготовка

1. Взять кредитную карту (или дебетовую, ID-карту)
2. Открыть экран калибровки
3. Убедиться, что браузер в полноэкранном режиме (F11)

### Шаг 2: Измерение

1. Приложить карту к экрану
2. Перетащить границы прямоугольника, чтобы совпали с картой
3. Измерить расстояние до экрана (линейкой или приблизительно)

**Интерфейс:**
```typescript
// Пользователь регулирует ширину
cardWidthPx = userDrag(); // например, 323 пикселя

// Расстояние (input)
distanceCm = userInput();  // например, 40 см
```

### Шаг 3: Сохранение

```typescript
interface Calibration {
  pixelsPerDegree: number;  // 26.4
  screenDistance: number;   // 40 см
  dpi: number;              // 96
  timestamp: number;        // Дата калибровки
}

// Сохранение в localStorage
localStorage.setItem('campimetry_calibration', JSON.stringify(calibration));
```

**Файл реализации:** `src/hooks/useCalibration.ts:60-70`

## Валидация калибровки

### Проверка разумности

```typescript
// DPI должен быть в разумном диапазоне
if (dpi < 50 || dpi > 400) {
  warning("Проверьте измерение карты");
}

// Расстояние должно быть физиологичным
if (distance < 20 || distance > 80) {
  warning("Расстояние должно быть 20-80 см");
}

// PPD не должен быть экстремальным
if (ppd < 10 || ppd > 100) {
  error("Калибровка некорректна");
}
```

### Рекомендации для точности

1. **Освещение:** Достаточное для видимости границ карты
2. **Браузер:** Полноэкранный режим (F11), 100% масштаб
3. **Карта:** Плотно прижата к экрану, без наклона
4. **Измерение:** Выровнять границы точно по краям
5. **Расстояние:** Измерить линейкой (не на глаз)

## Повторная калибровка

### Когда нужна?

- ✅ Смена монитора
- ✅ Изменение разрешения экрана
- ✅ Изменение расстояния (>5 см)
- ✅ Через 1+ месяц (проверочная)

### Хранение данных

```typescript
// Проверка актуальности
const calibration = loadCalibration();
const age = Date.now() - calibration.timestamp;

if (age > 30 * 24 * 60 * 60 * 1000) {
  suggest("Рекомендуем перекалибровку");
}
```
