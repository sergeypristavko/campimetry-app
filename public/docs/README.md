# Документация Campimetry App

### [Медицинский контекст](medical-context.md)
- Что такое периметрия и зачем она нужна

### [Тестовые паттерны](test-patterns.md)

- Яркость в децибелах (0-40 dB)
- Фоновая яркость и её значение
- Цвет стимула

## 🧮 Алгоритмы и расчёты

### [Алгоритмы тестирования](algorithms.md)
- **Пороговая стратегия:** Staircase 4-2 (детальное описание)
- **Надпороговая стратегия:** быстрый скрининг
- Обоснование параметров (24 dB начало, шаги 4→2 dB, 2 реверса)
- Преобразование dB в opacity
- Сравнение с SITA и ZEST

### [Статистические показатели](statistics.md)
- **MD (Mean Deviation)** — средняя девиация, глобальный индекс
- **PSD (Pattern Standard Deviation)** — локализованность дефектов
- **VFI (Visual Field Index)** — процент сохранности с весами
- **GHT (Glaucoma Hemifield Test)** — асимметрия полусфер
- Total Deviation vs Pattern Deviation
- Вероятностные карты (p-values)

### [Система калибровки](calibration.md)
- Зачем нужна калибровка экрана
- Метод кредитной карты (ISO/IEC 7810)
- Расчёт DPI (Dots Per Inch)
- Расчёт PPD (Pixels Per Degree)
- Преобразование градусы ↔ пиксели
- Источники ошибок и точность

## 📊 Качество и интерпретация

### [Показатели надёжности](reliability.md)
- **Fixation Losses** — контроль фиксации (метод Heijl-Krakau)
- **False Positives** — преждевременные ответы
- **False Negatives** — пропуск ярких стимулов
- Критерий приемлемости (< 33%)
- Влияние на интерпретацию результатов

### [Возрастные нормы](age-norms.md)
- Физиологическое снижение с возрастом (-0.7 dB/10 лет)
- Механизмы старения (потеря фоторецепторов, хрусталик, ганглиозные клетки)
- Нормативная база по эксцентриситету
- Расчёт Total Deviation и интерпретация

### [Ограничения и дисклеймер](limitations.md)
- ⚕️ **Медицинский дисклеймер** (обязательно к прочтению!)
- Преимущества домашнего тестирования
- Ограничения vs клинической периметрии
- Источники ошибок (технические, физиологические, психологические)
- Когда тест недостоверен
- Правильное использование приложения

## 🚀 Быстрый старт

### Для пользователей

1. **[Открыть приложение →](../)**
2. Пройти **[калибровку экрана](calibration.md)** (кредитная карта)
3. Изучить **[паттерны тестирования](test-patterns.md)**
4. Следовать инструкциям на экране
5. Интерпретировать **[статистические показатели](statistics.md)**

### Для разработчиков

```bash
# Клонировать репозиторий
git clone https://github.com/sergeypristavko/campimetry-app.git

# Установить зависимости
npm install

# Запустить dev сервер
npm run dev

# Собрать проект
npm run build
```

**Файловая структура:**
- `src/utils/algorithms.ts` — алгоритмы тестирования
- `src/utils/statistics.ts` — расчёт MD, PSD, VFI, GHT
- `src/utils/normalValues.ts` — возрастные нормы
- `src/utils/gridPatterns.ts` — паттерны 24-2, 10-2, 30-2
- `src/utils/calibration.ts` — калибровка экрана
- `src/hooks/useTest.ts` — основная логика теста

## ⚠️ Важное предупреждение

> **Медицинский дисклеймер:**
>
> Данное приложение предназначено **только для скрининга и самоконтроля**. Оно **НЕ заменяет** профессиональное офтальмологическое обследование.
>
> При обнаружении отклонений **обязательно обратитесь к врачу-офтальмологу** для полной диагностики.

Подробнее: **[Ограничения и дисклеймер →](limitations.md)**
