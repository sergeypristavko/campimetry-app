# Статистические показатели

## Обзор

Периметрия генерирует большой объём данных (54-76 точек × порог). Статистические индексы сжимают эту информацию в несколько чисел для:
- Выявления патологии
- Оценки тяжести
- Мониторинга прогрессирования
- Сравнения между тестами

**Основные индексы:**
- **MD** — Mean Deviation (средняя девиация)
- **PSD** — Pattern Standard Deviation (паттерн-стандартное отклонение)
- **VFI** — Visual Field Index (индекс поля зрения)
- **GHT** — Glaucoma Hemifield Test (глаукомный тест полусфер)

---

## Mean Deviation (MD)

### Определение

**MD** — средняя разница между измеренными порогами и возрастными нормами для всех точек.

### Формула

```typescript
// Для каждой точки
totalDeviation[i] = measuredThreshold[i] - normalThreshold[i]

// MD = среднее всех отклонений
MD = mean(totalDeviation)
```

**Пример:**
```
Точка 1: 28 dB (измерено) - 32 dB (норма) = -4 dB
Точка 2: 30 dB - 31 dB = -1 dB
Точка 3: 25 dB - 30 dB = -5 dB
...
MD = mean(-4, -1, -5, ...) = -3.2 dB
```

**Файл реализации:** `src/utils/statistics.ts:18-32`

### Интерпретация

| MD (dB) | Классификация | Клиническое значение |
|---------|---------------|----------------------|
| ≥ -2 | **Норма** | Здоровое поле зрения |
| -2 до -6 | **Лёгкая потеря** | Ранняя глаукома, требуется мониторинг |
| -6 до -12 | **Умеренная потеря** | Прогрессирование, интенсификация лечения |
| -12 до -20 | **Выраженная потеря** | Высокий риск слепоты |
| < -20 | **Тяжёлая потеря** | Критическая ситуация |

### Клиническое значение

**Глобальный индекс:**
- Отражает общую потерю чувствительности
- Чувствителен к диффузным дефектам (катаракта, диффузная глаукома)
- Коррелирует с качеством жизни [1]

**Прогрессирование:**
- Изменение MD > **2 dB/год** = быстрое прогрессирование [2]
- Изменение MD > **1 dB/год** = умеренное прогрессирование
- Изменение MD < **0.5 dB/год** = стабильное состояние

**Функциональное нарушение:**
- MD < -12 dB коррелирует с:
  - Затруднениями при чтении
  - Проблемами с ориентацией
  - Ограничениями в вождении [3]

### Ограничения

- ❌ Не различает **локализованные vs диффузные** дефекты
- ❌ Может быть **нормальным** при начальных локализованных скотомах
- ❌ Чувствителен к **артефактам** (катаракта, миоз, недостаточная коррекция)

**Источники:**
- [1] Sumi I, et al. "Visual disability and visual scores." Jpn J Ophthalmol. 2000;44(1):82-7.
- [2] Heijl A, et al. "Rates of visual field progression in clinical glaucoma care." Acta Ophthalmol. 2013;91(5):406-12.
- [3] Nelson P, et al. "Visual field progression in glaucoma." Ophthalmology. 2009;116(2):200-7.

## Pattern Standard Deviation (PSD)

### Определение

**PSD** — мера **неравномерности** (локализованности) потери поля зрения после компенсации общего снижения чувствительности.

### Алгоритм расчёта

```typescript
// Шаг 1: Рассчитать общие девиации
totalDeviations = measuredThresholds - normalThresholds

// Шаг 2: Найти 85-й перцентиль (компенсация общего снижения)
generalHeight = percentile(totalDeviations, 85)

// Шаг 3: Вычислить паттерн-девиации
patternDeviations = totalDeviations - generalHeight

// Шаг 4: PSD = стандартное отклонение паттерн-девиаций
PSD = standardDeviation(patternDeviations)
```

**Почему 85-й перцентиль?**
- **7-е по величине значение** из 54 точек (24-2)
- Устойчив к выбросам (локализованным дефектам)
- Представляет "общий фон" чувствительности
- Эмпирически установлено Heijl & Asman [4]

**Файл реализации:** `src/utils/statistics.ts:38-58`

### Интерпретация

| PSD (dB) | Классификация | Клиническое значение |
|----------|---------------|----------------------|
| ≤ 2 | **Норма** | Равномерное поле зрения |
| 2-4 | **Минимальная локализация** | Начальные дефекты |
| 4-6 | **Умеренная локализация** | Выраженные дефекты |
| > 6 | **Значительная локализация** | Глубокие локализованные скотомы |

### Клиническое значение

**Детекция локализованных дефектов:**
- PSD ↑ + MD норм. = **ранняя глаукома** (локализованные дефекты без общего снижения)
- PSD норм. + MD ↓ = **катаракта/миоз** (диффузное снижение)
- PSD ↑ + MD ↓ = **продвинутая глаукома** (и то, и другое)

**Специфичность к глаукоме:**
- Более специфичен, чем MD [5]
- Коррелирует с дугообразными скотомами
- Менее чувствителен к артефактам (катаракта)

**Пример:**

```
Пациент A: MD = -2 dB, PSD = 6 dB
  → Локализованный дефект (ранняя глаукома)

Пациент B: MD = -8 dB, PSD = 2 dB
  → Диффузное снижение (катаракта)
```

**Источники:**
- [4] Asman P, Heijl A. "Glaucoma Hemifield Test." Arch Ophthalmol. 1992;110(6):812-9.
- [5] Bengtsson B, Heijl A. "Diagnostic value of the mean deviation." Acta Ophthalmol Scand. 1996;74(4):323-6.

## Visual Field Index (VFI)

### Определение

**VFI** — процент сохранности поля зрения с учётом **центральной весовой функции** (центр важнее периферии).

### Формула расчёта

```typescript
// Для каждой точки
percentPreserved = (measuredThreshold / normalThreshold) × 100%

// Применить вес по эксцентриситету
weight = getVFIWeight(eccentricity)

// Взвешенная сумма
weightedSum += percentPreserved × weight

// VFI (%)
VFI = (weightedSum / totalWeight) × 100%
```

### Веса по эксцентриситету

| Эксцентриситет | Вес | Обоснование |
|----------------|-----|-------------|
| **0-5°** | **1.0** | Центральное зрение критично для чтения |
| 5-10° | 0.8 | Парацентральная зона |
| 10-15° | 0.6 | Функциональная зона |
| 15-20° | 0.4 | Ориентация в пространстве |
| 20-25° | 0.3 | Средняя периферия |
| > 25° | 0.2 | Дальняя периферия (минимальное влияние) |

**Обоснование весов:**
- Функциональная важность для повседневной активности
- Плотность ганглиозных клеток (фовеа 150,000/мм² vs периферия 3,000/мм²)
- Корреляция с субъективной оценкой качества зрения [6]

**Файл реализации:** `src/utils/statistics.ts:64-89`

### Интерпретация

| VFI (%) | Стадия глаукомы | Функциональное состояние |
|---------|-----------------|--------------------------|
| **≥ 95%** | **Норма** | Без ограничений |
| 80-95% | Лёгкая | Минимальные затруднения |
| 60-80% | Умеренная | Проблемы при чтении, вождении |
| 40-60% | Выраженная | Значительные ограничения |
| **< 40%** | **Тяжёлая** | Инвалидизация |

### Клиническое значение

**Функциональная оценка:**
- Коррелирует с повседневной активностью лучше, чем MD [7]
- Отражает субъективное восприятие потери зрения
- Используется для оценки инвалидности

**Мониторинг прогрессирования:**
- **Линейная шкала** (в отличие от логарифмической MD)
- Изменение VFI **-1%/год** = типичное прогрессирование
- Изменение VFI **-2%/год** = быстрое прогрессирование

**Преимущества перед MD:**
- ✅ Центрально-взвешенный (клинически релевантный)
- ✅ Линейный (удобен для тренд-анализа)
- ✅ Интуитивный (процент сохранности)

**Источники:**
- [6] Bengtsson B, Heijl A. "A visual field index for calculation of glaucoma rate of progression." Am J Ophthalmol. 2008;145(2):343-53.
- [7] Arora KS, et al. "Visual field index and quality of life." Ophthalmology. 2015;122(9):1719-26.

## Glaucoma Hemifield Test (GHT)

### Определение

**GHT** — тест для выявления **асимметрии** между верхней и нижней полусферами поля зрения, характерной для глаукомы.

### Алгоритм

```typescript
// Шаг 1: Разделить поле зрения на 5 парных секторов
sectors = [
  { upper: [точки_1], lower: [точки_1_mirror] },
  { upper: [точки_2], lower: [точки_2_mirror] },
  ...
]

// Шаг 2: Для каждой пары вычислить разницу
for (sector of sectors) {
  upperMean = mean(sector.upper)
  lowerMean = mean(sector.lower)
  difference = abs(upperMean - lowerMean)
}

// Шаг 3: Сравнить с нормативной базой (99.5-й перцентиль)
abnormalSectors = count(difference > threshold_99_5)

// Шаг 4: Классифицировать
if (abnormalSectors >= 2) return "outside normal limits"
if (abnormalSectors == 1) return "borderline"
if (MD < -3) return "general reduction"
return "within normal limits"
```

**Файл реализации:** `src/utils/statistics.ts:95-142`

### Категории результатов

| Результат | Значение | Клиническая интерпретация |
|-----------|----------|---------------------------|
| **Within normal limits** | Норма | Обе полусферы в пределах нормы |
| **Borderline** | Пограничное | Один сектор с асимметрией |
| **Outside normal limits** | Вне нормы | ≥2 секторов с асимметрией (типично для глаукомы) |
| **General reduction** | Общее снижение | Диффузная потеря без асимметрии (катаракта) |
| **Abnormally high sensitivity** | Аномально высокая | Парадокс (артефакт, ложноположительные) |

### Анатомическое обоснование

**Архитектура нервных волокон:**
- Аксоны ганглиозных клеток идут к диску зрительного нерва **дугообразно**
- Горизонтальный raphe разделяет верхние и нижние волокна
- Глаукоматозное повреждение следует этой анатомии

**Типичные паттерны:**
- Верхняя дуга поражена → нижнее поле зрения дефект
- Нижняя дуга поражена → верхнее поле зрения дефект
- **Асимметрия верх/низ = патогномонично для глаукомы**

### Клиническое значение

**Специфичность к глаукоме:**
- **Специфичность: 90-95%** [8]
- **Чувствительность: 60-70%** (ранние стадии)
- Менее чувствителен к артефактам, чем MD

**Раннее выявление:**
- Обнаруживает асимметрию **до значимых изменений MD**
- Полезен для скрининга

**Ограничения:**
- Менее чувствителен при диффузной глаукоме (оба полуполя равно поражены)
- Не применим при нейроофтальмологических дефектах (гемианопсии)

**Источники:**
- [8] Asman P, Heijl A. "Glaucoma Hemifield Test. Automated visual field evaluation." Arch Ophthalmol. 1992;110(6):812-9.

## Total Deviation vs Pattern Deviation

### Total Deviation (Общая девиация)

**Определение:** Разница между измеренным порогом и возрастной нормой.

```typescript
totalDeviation = measuredThreshold - normalThreshold
```

**Интерпретация:**
- Показывает абсолютное снижение чувствительности
- Включает **как локализованные, так и диффузные** дефекты
- Чувствителен к артефактам (катаракта, миоз, недокоррекция)

### Pattern Deviation (Паттерн-девиация)

**Определение:** Локализованное отклонение после коррекции общего снижения.

```typescript
generalHeight = 85th_percentile(totalDeviations)
patternDeviation = totalDeviation - generalHeight
```

**Интерпретация:**
- Показывает **только локализованные** дефекты
- Компенсирует диффузные изменения (катаракта, миоз)
- Более специфичен к глаукоме

### Пример сравнения

**Случай 1: Катаракта**
```
Total Deviation: все точки -8 dB (диффузное снижение)
Pattern Deviation: все точки ~0 dB (нет локализации)
→ Диагноз: катаракта, НЕ глаукома
```

**Случай 2: Глаукома**
```
Total Deviation: верхнее поле -12 dB, нижнее -2 dB
Pattern Deviation: верхнее поле -10 dB, нижнее 0 dB
→ Диагноз: глаукома (локализованный дефект)
```

**Файл реализации:** `src/utils/normalValues.ts:42-78`

## Вероятностные карты

### p-значения дефектов

Приложение вычисляет вероятность, что отклонение является патологическим:

| p-value | Символ | Интерпретация |
|---------|--------|---------------|
| **p < 0.5%** | ■■■■ | Очень вероятный дефект (99.5% уверенность) |
| **p < 1%** | ■■■ | Вероятный дефект (99% уверенность) |
| **p < 2%** | ■■ | Возможный дефект (98% уверенность) |
| **p < 5%** | ■ | Пограничный (95% уверенность) |
| **p ≥ 5%** | - | В пределах нормы |
