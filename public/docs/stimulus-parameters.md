# Параметры стимула

## Размер стимула: Goldmann

### Классификация Goldmann

**Герман Голдманн** (1945) стандартизировал размеры стимулов для периметрии [1].

| Размер | Диаметр | Угловой размер | Площадь | Применение |
|--------|---------|----------------|---------|------------|
| I | 0.25 мм | 0.108° (6.5') | 0.00916 мм² | Микропериметрия |
| II | 0.5 мм | 0.217° (13') | 0.0366 мм² | Центральные скотомы |
| **III** | **1 мм** | **0.431° (26')** | **0.146 мм²** | **🌟 Стандарт** |
| IV | 2 мм | 0.862° (52') | 0.583 мм² | Периферия |
| V | 4 мм | 1.724° (104') | 2.33 мм² | Выраженные дефекты |

**Примечание:** Угловые размеры указаны для расстояния 30 см.

### Почему Goldmann III?

**Goldmann III** — международный стандарт для автоматизированной периметрии [2].

**Преимущества:**
- ✅ Оптимальный баланс между локализацией и надёжностью обнаружения
- ✅ Высокая воспроизводимость: тест-ретест вариабельность 1.5-2 dB [3]
- ✅ Стандартизация для клинических исследований
- ✅ Эквивалентность ~200 фоторецепторов на расстоянии 30 см

**Когда использовать другие размеры:**
- **Goldmann I/II:** Микропериметрия (детальное макулярное тестирование)
- **Goldmann IV/V:** Пациенты с низкой остротой зрения, сниженной прозрачностью сред

**Источники:**
- [1] Goldmann H. "Grundlagen exakter Perimetrie." Ophthalmologica. 1945;109(2-3):57-70.
- [2] Anderson DR, Patella VM. "Automated Static Perimetry." 2nd ed. Mosby; 1999.
- [3] Artes PH, et al. "Properties of perimetric threshold estimates." Invest Ophthalmol Vis Sci. 2002;43(8):2654-9.

### Расчёт размера в пикселях

**Формула:**
```typescript
// Из калибровки
pixelsPerDegree = расстояние_см × (DPI / 2.54) × tan(1°)

// Размер стимула
sizeDegrees = GoldmannSizes[size] // например, 0.431° для III
sizePixels = sizeDegrees × pixelsPerDegree

// Минимум 4 пикселя
sizePixels = Math.max(4, sizePixels)
```

**Пример:**
- Расстояние: 40 см
- DPI: 96
- PPD: ~26.4 пикселя/градус
- Goldmann III: 0.431° × 26.4 ≈ **11.4 пикселя**

## Длительность стимула

### Диапазон

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| Минимум | 100 мс | Предотвращение саккад [4] |
| **По умолчанию** | **200 мс** | **Клинический стандарт Humphrey** |
| Максимум | 500 мс | Граница перед микросаккадами |

### Почему 200 мс?

**Физиология зрительного восприятия:**

1. **Латентность обнаружения:** 50-100 мс (время от стимула до осознания)
2. **Время принятия решения:** 50-100 мс
3. **Моторная реакция:** 50-100 мс
4. **Латентность саккады:** 200-250 мс [5]

При **200 мс:**
- ✅ Достаточно для надёжного обнаружения
- ✅ Недостаточно для произвольной рефиксации
- ✅ Стандарт Humphrey Field Analyzer (100-200 мс) [6]

**Источники:**
- [4] Keltner JL, et al. "Effects of stimulus duration on static threshold variance." Invest Ophthalmol Vis Sci. 1980;19(1):101-5.
- [5] Fischer B, Ramsperger E. "Human express saccades." Exp Brain Res. 1984;57(1):191-5.
- [6] Bengtsson B, Heijl A. "False-negative responses in glaucoma perimetry." Am J Ophthalmol. 2000;130(5):689-91.

## Яркость стимула

### Шкала децибел (dB)

**Децибел** — логарифмическая единица, используемая в периметрии для измерения яркости.

**Формула:**
```
dB = 10 × log₁₀(L_max / L_stim)
```

где:
- `L_max` = максимальная яркость прибора (10,000 asb для Humphrey)
- `L_stim` = яркость стимула

### Диапазон в приложении

| Яркость | Opacity | Клиническое значение |
|---------|---------|----------------------|
| **0 dB** | 1.0 | Максимальная яркость (ярчайший стимул) |
| 10 dB | 0.77 | Супрапороговое значение |
| 20 dB | 0.54 | Среднее |
| **24 dB** | **0.45** | **Начальная интенсивность** |
| 30 dB | 0.31 | Нормальная периферия |
| **40 dB** | 0.08 | Минимальная яркость (тусклейший стимул) |

**Формула преобразования:**
```typescript
minOpacity = 0.08;    // 40 dB
maxOpacity = 1.0;     // 0 dB

opacity = maxOpacity - (intensityDb / 40) × (maxOpacity - minOpacity)
        = 1.0 - (intensityDb / 40) × 0.92
        = 1.0 - intensityDb × 0.023
```

**Файл реализации:** `src/utils/algorithms.ts:168-174`

### Физиологический контекст

**Нормальная чувствительность по зонам:**
```
Фовеа (0°):        35-40 dB (максимальная чувствительность)
Парафовеа (5°):    31-32 dB
Макула (10°):      29 dB
Средняя зона (15°): 27 dB
Периферия (24°):   24 dB
Дальняя периферия (30°): 22 dB
```

**Интерпретация дефектов:**
- **> 30 dB:** Отличная чувствительность
- **25-30 dB:** Нормальная периферия
- **15-25 dB:** Относительная скотома
- **< 15 dB:** Абсолютная скотома
- **0 dB:** Стимул не виден даже на максимальной яркости

## Цвет стимула

### По умолчанию: белый (#FFFFFF)

**Стандарт Humphrey:** Белый свет широкого спектра.

**Почему белый?**
- Стимулирует все типы колбочек (L, M, S)
- Максимальный контраст на сером фоне
- Стандартизация и сравнимость результатов

### Альтернативные цвета (экспериментально)

| Цвет | Длина волны | Применение |
|------|-------------|------------|
| Красный | ~620 nm | Тестирование L-колбочек |
| Зелёный | ~530 nm | Тестирование M-колбочек |
| Синий | ~470 nm | Тестирование S-колбочек, SWAP |

**SWAP (Short Wavelength Automated Perimetry):**
- Синий стимул на жёлтом фоне
- Ранняя диагностика глаукомы (S-колбочки страдают первыми)
- Не реализовано в текущей версии

## Фоновая яркость

### Средний серый: RGB(128, 128, 128)

**Обоснование:**

Humphrey Field Analyzer использует **10 cd/m²** (31.5 asb) [7]. Средний серый на стандартном мониторе (~80-100 cd/m²) создаёт **мезопические условия** (сумеречное зрение).

**Преимущества:**
- ✅ Активация палочек И колбочек
- ✅ Стабильная фиксация без утомления
- ✅ Широкий динамический диапазон контраста
- ✅ Физиологическая адаптация за 3-5 минут

**Источники:**
- [7] Heijl A, et al. "Test-retest variability in glaucomatous visual fields." Am J Ophthalmol. 1989;108(2):130-5.

## Таймлайн презентации

```
t=0ms:    Начало межстимульного интервала (500-1000 мс случайно)
          └─> Предотвращение предсказуемости, поддержка внимания

t=500-1000ms: Показ стимула
              └─> Opacity от 0 до calculated_value за 50ms
              └─> Длительность: stimulusDuration (200 мс по умолчанию)

t=200ms:  Скрытие стимула
          └─> Opacity от value до 0 за 50ms

t=200ms:  Начало ожидания ответа
          └─> Timeout: responseTimeout (2000 мс по умолчанию)

Ответ пользователя ИЛИ timeout:
  └─> Обработка ответа
  └─> Обновление алгоритма
  └─> Следующий стимул
```
