# Возрастные нормы

## Старение и чувствительность сетчатки

### Физиологическое снижение

С возрастом чувствительность сетчатки **естественно снижается**:

```
Коррекция = -0.7 dB на каждые 10 лет после 30 лет
```

**Примеры:**
```
Возраст 30 лет: 0 dB коррекции (базовый уровень)
Возраст 40 лет: -0.7 dB
Возраст 50 лет: -1.4 dB
Возраст 60 лет: -2.1 dB
Возраст 70 лет: -2.8 dB
Возраст 80 лет: -3.5 dB
```

**Формула:**
```typescript
ageCorrection = -0.7 × ((age - 30) / 10)
correctedSensitivity = baseSensitivity + ageCorrection
```

**Файл реализации:** `src/utils/normalValues.ts:31-34`

## Механизмы возрастного снижения

### 1. Потеря фоторецепторов

- **Колбочки:** ~30% потеря к 80 годам [1]
- **Палочки:** ~20% потеря к 80 годам
- Наиболее выражено в периферии

**Источник:**
- [1] Gao H, Hollyfield JG. "Aging of the human retina." Invest Ophthalmol Vis Sci. 1992;33(1):1-17.

### 2. Снижение прозрачности хрусталика

| Возраст | Светопропускание |
|---------|------------------|
| 20 лет | 100% (базовый) |
| 40 лет | ~85% |
| 60 лет | ~70% |
| 80 лет | ~50% |

**Механизм:** Накопление белковых агрегатов, пожелтение

**Источник:**
- [2] Pokorny J, et al. "Aging of the human lens." Appl Opt. 1987;26(8):1437-40.

### 3. Деградация пигментного эпителия

- Накопление **липофусцина** (возрастной пигмент)
- Снижение эффективности фототрансдукции
- Замедление регенерации родопсина

### 4. Потеря ганглиозных клеток

- **~5,000-10,000 клеток/год** после 40 лет [3]
- Общая потеря ~30-40% к 80 годам
- Неравномерная: височная часть сетчатки страдает больше

**Источник:**
- [3] Balazsi AG, et al. "Age effect on nerve fiber population of the optic nerve." Am J Ophthalmol. 1984;97(6):760-6.

### Градиент чувствительности

**Центр → периферия:** Снижение ~0.5 dB/градус

**Причина:** Плотность ганглиозных клеток

```
Фовеа:     150,000 клеток/мм²
Периферия:   3,000 клеток/мм²

Соотношение: 50:1
```

## Расчёт нормы для точки

### Алгоритм

```typescript
function getAgeNormalSensitivity(
  eccentricity: number,
  age: number
): number {
  // 1. Базовая чувствительность для эксцентриситета
  const baseSensitivity = interpolate(eccentricity, AGE_NORMAL_MAP);
  
  // 2. Возрастная коррекция
  const ageCorrection = -0.7 * ((age - 30) / 10);
  
  // 3. Итоговая норма
  return baseSensitivity + ageCorrection;
}
```

**Пример:**
```
Точка: 12° эксцентриситет
Возраст: 60 лет

Базовая чувствительность (30 лет): 28 dB
Возрастная коррекция: -0.7 × (30/10) = -2.1 dB
Норма для 60 лет: 28 - 2.1 = 25.9 dB
```

**Файл реализации:** `src/utils/normalValues.ts:42-78`

## Интерполяция между точками

Для эксцентриситетов, не указанных в таблице, используется **линейная интерполяция**:

```typescript
// Пример: эксцентриситет 13°
// Известны: 12° → 28 dB, 15° → 27 dB

const e1 = 12, s1 = 28;
const e2 = 15, s2 = 27;
const e = 13;

// Линейная интерполяция
sensitivity = s1 + (s2 - s1) * (e - e1) / (e2 - e1)
            = 28 + (27 - 28) * (13 - 12) / (15 - 12)
            = 28 + (-1) * 1/3
            = 27.67 dB
```

## Девиации от нормы

### Total Deviation

**Абсолютное отклонение** от возрастной нормы:

```typescript
totalDeviation = measuredThreshold - normalThreshold

// Пример
Измерено: 23 dB
Норма: 28 dB
Total Deviation: 23 - 28 = -5 dB (снижение)
```

### Интерпретация девиаций

| Девиация | Интерпретация |
|----------|---------------|
| **+3 dB** | Выше нормы (возможно FP) |
| **0 ±2 dB** | Норма |
| **-2 до -5 dB** | Лёгкое снижение |
| **-5 до -10 dB** | Умеренное снижение |
| **-10 до -20 dB** | Выраженное снижение |
| **< -20 dB** | Тяжёлое снижение |

**Файл реализации:** `src/utils/normalValues.ts:81-93`

## Вероятность дефекта

Девиация сравнивается с **нормальным распределением** здоровой популяции:

| Девиация | p-value | Вероятность дефекта |
|----------|---------|---------------------|
| 0 ±3 dB | p > 5% | Норма |
| -3 до -5 dB | **p < 5%** | Пограничное |
| -5 до -7 dB | **p < 2%** | Вероятный дефект |
| -7 до -10 dB | **p < 1%** | Достоверный дефект |
| < -10 dB | **p < 0.5%** | Глубокий дефект |

**Файл реализации:** `src/utils/normalValues.ts:100-118`
