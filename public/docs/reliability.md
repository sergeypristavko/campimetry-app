# Показатели надёжности

## Зачем нужны индексы надёжности?

Периметрия — **субъективный тест**, требующий:
- Концентрации внимания (~6-8 минут)
- Стабильной фиксации взгляда
- Быстрой моторной реакции

**Индексы надёжности** помогают отличить:
- ✅ Реальные дефекты поля зрения
- ❌ Артефакты (утомление, непонимание, симуляция)

---

## Типы проверок

| Индекс | Что проверяет | Норма | Ненадёжный тест |
|--------|---------------|-------|-----------------|
| **Fixation Losses** | Стабильность фиксации | < 20% | > 33% |
| **False Positives** | Преждевременные ответы | < 15% | > 33% |
| **False Negatives** | Пропуск ярких стимулов | < 20% | > 33% |

---

## Потери фиксации (Fixation Losses)

### Метод Heijl-Krakau

**Принцип:** Периодически показывать стимулы в слепом пятне.

```typescript
// Слепое пятно
const blindSpotX = isRightEye ? 15 : -15;  // градусов
const blindSpotY = -1.5;
const radius = 5;

// Если пациент ответил → потеря фиксации
if (responseInBlindSpot) fixationLosses++;
```

**Анатомия слепого пятна:**
- Диск зрительного нерва (~15° назально, 1.5° вниз)
- Диаметр ~5-7°
- Физиологически слепая зона (нет фоторецепторов)

**Интерпретация:**

| FX Loss | Оценка | Проблема |
|---------|--------|----------|
| < 20% | ✅ Отлично | Стабильная фиксация |
| 20-33% | ⚠️ Приемлемо | Небольшие сдвиги взгляда |
| > 33% | ❌ Ненадёжно | Плохая фиксация/не понял инструкцию |

**Ложные срабатывания:**
- Расширенное слепое пятно (отёк диска)
- Пациент ответил по инерции (угадал)

**Источник:** Heijl A, Krakau CE. "An automatic static perimeter." Acta Ophthalmol. 1975;53(3):293-310.

## Ложноположительные ответы (False Positives)

### Метод

**Catch trial:** Периодически НЕ показывать стимул (пустая презентация).

```typescript
// 10-15% презентаций — без стимула
if (randomCatchTrial && patientResponded) {
  falsePositives++;
}
```

**Интерпретация:**

| FP Rate | Оценка | Проблема |
|---------|--------|----------|
| < 15% | ✅ Норма | Адекватные ответы |
| 15-33% | ⚠️ Повышен | Торопится / нажимает наугад |
| > 33% | ❌ Ненадёжно | "Trigger happy" / симуляция |

**Клиническое значение:**
- Высокий FP → **завышенная чувствительность**
- Пороги измерены ниже реальных
- Ложная норма при наличии дефектов

**Типичные причины:**
- Тревожность (боится пропустить)
- Непонимание инструкции
- Умышленная симуляция

## Ложноотрицательные ответы (False Negatives)

### Метод

**Повторная презентация:** Показать стимул на 9 dB **ярче** измеренного порога.

```typescript
// Порог измерен: 28 dB
// FN проверка: показать 19 dB (на 9 dB ярче)

if (noResponse && intensity < threshold - 9) {
  falseNegatives++;
}
```

**Интерпретация:**

| FN Rate | Оценка | Проблема |
|---------|--------|----------|
| < 20% | ✅ Норма | Внимательный пациент |
| 20-33% | ⚠️ Повышен | Утомление / отвлечение |
| > 33% | ❌ Ненадёжно | Сильное утомление |

**Клиническое значение:**
- Высокий FN → **заниженная чувствительность**
- Пороги измерены выше реальных
- Ложные дефекты

**Важное исключение:**
При **выраженной глаукоме** высокий FN может быть **не артефактом**, а реальной вариабильностью в глубоких скотомах!

**Источник:** Bengtsson B, Heijl A. "False-negative responses in glaucoma perimetry." Invest Ophthalmol Vis Sci. 1993;34(8):2442-4.

---

## Критерии приемлемости теста

### Правило 33%

Тест считается **надёжным**, если:

```typescript
fixationLosses < 33%
AND falsePositives < 33%
AND falseNegatives < 33%
```

Если хотя бы **один показатель > 33%** → рекомендуется **повтор** теста.

### Влияние на интерпретацию

| Паттерн | Вероятная причина | Действия |
|---------|-------------------|----------|
| FP ↑, FN норм | Торопливость | Повторить с инструкцией "не торопиться" |
| FP норм, FN ↑ | Утомление | Сократить тест (надпороговая стратегия) / перерыв |
| FX ↑ | Плохая фиксация | Проверить остроту зрения, повторить |
| Все ↑ | Непонимание / симуляция | Детальная инструкция, наблюдение |

**Источник:** Katz J, et al. "Reliability of visual field testing in the Glaucoma Laser Trial." Ophthalmology. 1995;102(10):1497-504.

## Реализация в приложении

### Частота проверок

```typescript
// Fixation Losses: каждая 10-я точка в слепом пятне
if (pointIndex % 10 === 0 && isBlindSpot(point)) {
  checkFixation();
}

// False Positives: 10-15% презентаций без стимула
if (random() < 0.12) {
  catchTrial(); // Нет стимула
}

// False Negatives: после завершения точки
if (thresholdMeasured && random() < 0.15) {
  checkFN(threshold - 9); // На 9 dB ярче
}
```

**Файл реализации:** Планируется в `src/hooks/useTest.ts`
